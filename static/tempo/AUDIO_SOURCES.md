# Audio sources (sound preview page only; the main page has no sound)

Both recordings are used as recorded (no denoising, no EQ), only cut and resequenced so the engine rpm follows the executed
speed-up: A with rpm-matched grains of the start-up rev-up / rev-down (tools/page_v19/v42_rev_sync_audio.py), B by playing the
recording on continuously and gently steering its read position (tools/page_v19/v43_f355_follow.py).

- A: "Lambo Start Up Sound" by JaimeLopes, Freesound #564373 (Lamborghini Huracán EVO Spyder V10),
  https://freesound.org/people/JaimeLopes/sounds/564373/ — CC0 1.0. Only 1.15–4.2 s is used (start-up and the clean idle
  after it); the later part with voices, birds and children is not used.
- B: "ferrari355underhood4.mp3" by enginemusic, Freesound #43484, https://freesound.org/people/enginemusic/sounds/43484/
  — CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/), attribution required. Used: rev-up 2–7 s and drop 7.0–7.6 s;
  cut and resequenced.
